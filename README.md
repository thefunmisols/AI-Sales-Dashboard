# AI-Powered-Sales-Dashboard
This is an AI powered dashboard that visualizes the sales data helping to make fast decisions

# Objective
This project demonstrates how to build an interactive, AI-powered dashboard using Python, Streamlit, Pandas, and Plotly.
Users can:
Load and filter sales data and other kinds of data
View interactive bar and pie charts
Get smart auto-generated insights based on data
Experience a clean, emoji-enhanced interface for engagement



# Run the App
streamlit run app.py

Then open your browser and go to: http://localhost:8501
